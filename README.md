# SystemMonitorX
<img src='system.gif'>

## Descrição

O SystemMonitorX é um programa de monitoramento de desempenho do PC que permite acompanhar e analisar métricas importantes do sistema em tempo real.

## Recursos

- Monitoramento de CPU
- Monitoramento de uso de memória RAM
- Monitoramento de uso de disco
- Monitoramento de temperatura do processador
- Gráficos e estatísticas detalhados

## Instalação

1. Clone este repositório para o seu computador.
2. Certifique-se de ter o Poetry instalado no seu sistema. Se não tiver, você pode instalá-lo usando o pip:

---pip install poetry



3. Com o Poetry instalado, navegue até o diretório raiz do projeto e execute o seguinte comando para instalar as dependências:


---poetry install



Isso instalará todas as dependências listadas no arquivo `pyproject.toml`.

4. Execute o arquivo `system_monitor.py` para iniciar o programa.
